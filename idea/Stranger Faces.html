Type any name. The same name always draws the same pixel animal, on every phone and laptop, with nothing stored on the server.

The room tonight

Every face below is drawn from its name alone. Tap one to inspect it.

Rarity

Rarity comes from the name too, so a legendary name is legendary for everyone who types it.

The rules each animal follows

Every feature is picked inside the range its species allows, so a frog never gets cat ears and a bunny never wears a cap over its ears.

How a name becomes a face

  1. NormalizeTrim, lowercase, fold look-alike characters. "Night_Owl " and "night_owl" match.
  2. HashA 53-bit hash of the name seeds a random number generator.
  3. Draw 24 numbersAlways in the same order. Each trait owns one slot, so new traits never change old faces.
  4. Pick inside the rulesSpecies first, then every feature within that species' ranges.
  5. Paint 24 x 24Layers, outline, cached as a tiny image. About 200 bytes per face.
