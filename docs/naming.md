## Why an exact-match domain

Google tends to surface a domain that equals the search phrase (chess.com
for "chess"), and searchers click results whose URL says what they typed.
The domain only helps if the site behind it is fast and has a page per
search phrase, so the plan pairs one domain with keyword landing pages.
